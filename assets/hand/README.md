# HAND+2mm Local Runtime Assets

This directory only keeps the verified left/right hand `HAND_*_PINKY_PLUS_2MM.npz` files.
The original PKL/NPZ files have been removed from the project.

The default backend is fixed to `hand_pinky_plus_2mm` (see
`algorithm/runtime_backend.py`; the former `local_runtime_override.json`
was removed during the SDK cleanup). Model provenance, licensing, and distribution
boundaries are described in `LICENSE.txt` in this directory.
