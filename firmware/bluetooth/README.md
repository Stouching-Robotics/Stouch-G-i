# STM32 手套固件 — 蓝牙版

本 SDK 对接的硬件：STM32 灵巧手，16×BNO055 IMU + 16×16 触觉压力矩阵 → CH9438 → USB CDC / 蓝牙 SPP。

当前固件版本：**v2.0.1**（蓝牙版）

## 变更说明

- 蓝牙版本 **2.0.1**，针对量产进行适配性修改。
- 降低开机时间，测试时间为 **2.3s**。
- 提升蓝牙功能稳定性。
- 兼容有线版（USB CDC），帧率稳定。
- 只需**拔插 dongle** 即可实现换机连接。

## 无线架构

```
手套: STM32 ──UART──▶ FSC-BT9104 (从机, 广播名 "traphand")
                        │  SPP 空中
                        ▼
PC: BP101Y dongle (主机) ──USB CDC──▶ COM 口 (VID 0483 PID 2013)
```

## 文件

| 文件 | 烧录地址 | 说明 |
|---|---|---|
| `bootloader.bin` / `bootloader.hex` | `0x08000000` (32KB) | Bootloader，左右手共用，出厂烧一次 |
| `left/stm32_imu_usb.bin` / `.hex` | `0x08008000` (96KB) | APP 固件（左手序） |
| `right/stm32_imu_usb.bin` / `.hex` | `0x08008000` (96KB) | APP 固件（右手序） |

## 烧录顺序

1. 先烧 `bootloader.hex`（地址 `0x08000000`）
2. 再烧对应手的 APP：`left/` 或 `right/` 下的 `stm32_imu_usb.hex`（地址 `0x08008000`）

> 若设备出厂已烧好 bootloader，只需烧 APP 即可。

## 蓝牙连接（换机）

绑定完成后，只需**拔插 dongle** 即可实现换机连接（手套重启自动连 dongle，无需重新配对）。
